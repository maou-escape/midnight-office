# Midnight Office

자정의 회사에 갇힌 1인용 방탈출 웹게임. 방을 조사하고, 물건을 쓰고, 서로 독립된 기록을 맞대어 진실을 확정한 뒤 퇴근하세요.

**플레이:** https://maou-escape.github.io/midnight-office/

| 에피소드 | 막 |
| --- | --- |
| Episode 1. 야근 | Act 1 정전 · Act 2 기록 · Act 3 복제 · Act 4 원본 · Act 5 퇴근 |
| Episode 2. 인수인계 | Act 1 첨부 파일 · Act 2 명단 |

- 막마다 30~50분, 자동 저장
- 막힐 때는 위쪽 `?` 버튼으로 진행 힌트, 장치 안에서는 3단계 힌트
- 휴대폰에서도 플레이할 수 있습니다 (가로 화면 권장)

글 선택형이던 원작을 방 조사형으로 다시 만든 리메이크입니다.
