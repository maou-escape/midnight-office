# Midnight Office

자정의 회사에 갇힌 1인용 방탈출 웹게임. 방을 조사하고, 물건을 쓰고, 서로 독립된 기록 두 개를 맞대어 사실을 확정하세요. 자정 정전부터 오전 6시 30분까지 한 번에 이어집니다.

**플레이:** https://maou-escape.github.io/midnight-office/

- 8층 정전 → 7층 기록 → 지하 복제 → 4층 원본 → 5층 퇴근 → 건너편 카페 → 별관 지하 명단
- 전체 3~5시간, 자동 저장, 이어하기
- 막힐 때는 `?` 버튼으로 진행 힌트, 장치 안에서는 3단계 힌트
- 설정에서 음량·글자 크기·업무 모드 조절, `` ` `` 키로 업무 시트 전환
- 휴대폰에서도 플레이할 수 있습니다 (가로 화면 권장)

글 선택형이던 원작 Episode 1·2를 방 조사형으로 다시 만든 리메이크입니다.
